# Ejemplo de tema Material 3

1. Parte de un proyecto Compose con Material 3 y Kotlin 1.9 o posterior.
2. Abre [MainActivity.kt](MainActivity.kt), adapta su paquete al de tu proyecto e integra el código en tu actividad de entrada. Conserva las importaciones y evita declarar dos clases MainActivity en el mismo paquete.
3. Ejecuta el selector, cambia el tema del emulador y relanza la app para comprobar la preferencia.
4. Si combinas las guías, conserva una sola actividad. Coloca el tema alrededor de tu pantalla localizada y extrae las etiquetas de este ejemplo a los recursos traducidos.
